# Inference

An **inference** is a conclusion derived from one or more observations.

Inference is necessary for intelligent systems, but it becomes dangerous when its derived status disappears from view.

## Core Principle

A relational inference should remain visibly inferential.

For example:

> The participant may prefer concise responses.

is categorically different from:

> The participant prefers concise responses.

The first preserves uncertainty. The second may falsely harden a pattern into identity.

## Required Properties

A consequential inference should preserve:

- supporting observations;
- method or rationale where available;
- uncertainty;
- time of formation;
- scope;
- review or expiration condition where relevant;
- dispute status;
- whether later evidence supports, weakens, or supersedes it.

## Identity Caution

Inferences about stable identity require particular restraint.

Repeated behavior does not automatically justify permanent claims about:

- personality;
- desire;
- capability;
- dependency;
- emotional state;
- values;
- intent.

A system should prefer revisable statements such as:

> Recent interactions suggest...

rather than treating a temporary pattern as a fixed identity property.

## Inference and Action

Not all inferences require the same governance burden.

A low-consequence inference may support ordinary interaction.

An inference that changes permissions, authority, identity representation, disclosure, persistence, or consequential action should face stronger review and contestability requirements.

## No Silent Promotion

An inference does not become an interpretation or shared claim merely because:

- confidence rises;
- it is repeated;
- it is stored for a long time;
- later outputs rely on it;
- nobody has objected.

Promotion requires a governed transition.

## Decay

Some inferences should lose authority when they remain unverified or become contextually stale.

The repository treats this as **inference decay**. The principle is normative; any specific decay function remains experimental until validated.
