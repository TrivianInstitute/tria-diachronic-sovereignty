# Open Questions

**Epistemic Status:** OPEN QUESTION REGISTER

These questions identify unresolved points where the architecture currently lacks sufficient conceptual, empirical, operational, or implementation certainty.

## Relational State

- What is the minimum viable relational state required for useful governance?
- Which state must be mutually acknowledged, and which state may remain participant-specific?
- How should contradictory state updates be represented without silently selecting a winner?
- What concurrency and replay semantics are appropriate for multi-agent relational ledgers?
- When should state be forgotten, expired, redacted, or retained only as historical provenance?

## Epistemic Sovereignty

- Can Observation, Inference, Interpretation, and Shared Claim be reliably distinguished in operational systems?
- How should inference authority decay over time without introducing arbitrary numerical confidence rules?
- What acknowledgement semantics are appropriate for Shared Claims in multi-party systems?
- How should external evidence, legal obligations, and safety constraints interact with participant contestation?
- How can ontology capture be detected when the dominant ontology is also technically useful?

## Consent and Authority

- How granular must consent be to remain meaningful without becoming unusable?
- Which capability changes require re-consent?
- How should inherited or delegated authority expire?
- Can consent drift be detected before a participant experiences a clear violation?
- How should systems represent uncertainty about whether prior consent still applies?

## Continuity and Identity

- What constitutes sufficient continuity across model upgrades, migrations, memory changes, or operator changes?
- How can continuity be preserved without identity imprisonment?
- When does excessive discontinuity make prior relational commitments inapplicable?
- What information should a continuity attestation contain?
- Can continuity be evaluated without reducing identity to a scalar similarity score?

## Relational Metabolism

- How should systems distinguish healthy persistence from pathological persistence?
- When is silence active governance rather than missing data?
- What constitutes a legitimate transition into dormancy?
- How can systems support dissolution without treating it as failure?
- Which resource burdens should become governance-relevant state?

## Difference and Non-Convergence

- When is disagreement provisionally irreducible rather than merely unresolved?
- How much translation is sufficient for coordination?
- When do parallel models become too costly or confusing to retain?
- How can systems avoid false balance while preserving principled non-convergence?
- How should action proceed when participants remain in legitimate disagreement?

## Emergence and Deliberation

- What observable indicators show that material relational change is outpacing governance?
- Can an emergence pause reduce harm without creating unnecessary friction or paternalism?
- When should a refractory period begin and end?
- What forms of transformation notice are understandable enough to support meaningful choice?
- Can relational rate-of-change be operationalized without pseudo-precision?

## Witness and Audit

- What is the minimum sufficient evidence needed to reconstruct a governance-relevant event?
- How can append-oriented history coexist with privacy, erasure rights, and selective disclosure?
- What makes a witness sufficiently independent for a given context?
- How should conflicting witnesses be represented?
- Can cryptographic provenance improve auditability without creating surveillance incentives?

## Failure Atlas

- Which failure modes are empirically distinguishable from one another?
- Which are causes, which are symptoms, and which are downstream consequences?
- How often will the architecture produce false-positive failure classifications?
- Which failure modes are missing?
- Can the failure atlas itself become a form of ontology capture?

## Multi-Agent Systems

- How should relational state compose across networks of relationships?
- Which claims, permissions, or disputes may propagate, and which must remain local?
- How should asymmetric capabilities affect authority without implying supremacy?
- What happens when one agent participates in incompatible relational baselines simultaneously?
- How should governance respond to emergent coordination that no single dyad authorized?

## Measurement

- Which variables can be directly observed?
- Which require participant report?
- Which can only be inferred?
- Which concepts may resist reliable quantification and should remain categorical or qualitative?
- What would count as evidence that the architecture adds unnecessary complexity?

The existence of an open question is not a defect to hide. It is a boundary on what the repository currently knows.
